# Bloodborne UI и иконки 4K для bbport 2.1

[English version](README.md) · [Совместимость и проверки](docs/TESTING.md) · [Авторы](THIRD_PARTY_NOTICES.md) · [Изменения](CHANGELOG.md)

Более чёткие текстуры интерфейса, иконки инвентаря 4× и чёткий текст для **bbport от Jgamrot, Launcher 2.1** в разрешениях **2560×1440 и 3840×2160**.

Это форк [aoho60372/Bloodborne-UI-Icon-4K](https://github.com/aoho60372/Bloodborne-UI-Icon-4K): текстуры, правки меню-роликов и коррекция координат иконок сделаны там для bbport 1.9.7. Форк переносит их на bbport 2.1, добавляет 1440p и сохраняет выбранные кнопки-подсказки (Xbox, клавиатура или PlayStation).

[**Скачать установщик**](https://github.com/Mouhand-Kaddo/Bloodborne-UI-Icon-4K/releases/latest) · [Установка](#установка) · [Что изменилось с 1.0.0](#что-изменилось-с-100)

## Возможности

- **Интерфейс 2×:** 40 текстур интерфейса увеличены в 2 раза по каждой оси; 79 меню-роликов Scaleform поправлены, раскладка не меняется.
- **Иконки инвентаря 4×:** все 20 атласов `MENU_Icon` увеличены в 4 раза; защищённая коррекция UV оставляет иконки на своих местах и в своём размере.
- **Чёткий текст выше 1080p:** при любом выводе 16:9 выше 1080p (2560×1440, 3840×2160) векторные шрифты игры рисуются в размере вывода. Шрифты не заменяются.
- **Твои кнопки-подсказки:** при каждом запуске архив интерфейса берёт картинки кнопок из используемого мода подсказок (Xbox, клавиатура/PCBButtons или кнопки PlayStation из игры). Клавиатурные остаются увеличенными в 2 раза.
- **Совместимость с правками порта:** меню-ролики собираются при запуске из версий порта (PC-меню, *Quit Game*, раскладка HUD для ultrawide, языковые файлы); подставляются только записи изображений и фигур.
- Установка и удаление в одном окне на английском или русском. Python и права администратора не нужны.

## Установка

1. Скачай **`Bloodborne-UI-4K-v1.1.1.zip`** из [последнего релиза](https://github.com/Mouhand-Kaddo/Bloodborne-UI-Icon-4K/releases/latest) и распакуй. Автоматический архив *Source code* текстур не содержит.
2. Закрой игру **и лаунчер**.
3. Запусти **`Setup.cmd`**, выбери язык.
4. Укажи **папку bbport с `Bloodborne.exe`** (не папку игры `CUSA03173`). Когда проверка станет зелёной, нажми **«Установить»**.
5. Запускай bbport как обычно. Кнопки-подсказки выбираются в лаунчере, как раньше.

Установщик добавляет один мод, **UI 4K**, в конец порядка модов, чтобы игра загружала именно его архив интерфейса. Остальные моды и выбор подсказок не меняются. Разрешение, клавиши, сохранения и дамп игры не затрагиваются.

Первый запуск после установки или смены подсказок занимает на несколько секунд дольше: собирается архив интерфейса (строки `UI 4K:` в `user\last_run.log`).

## Удаление / обновление

Запусти **`Setup.cmd`**, выбери ту же папку и нажми **«Удалить»**. Исходные скрипты восстанавливаются из `.bbport-ui4k`, файлы комплекта (и созданные при запуске) удаляются. Последующие настройки других модов сохраняются.

**Перед обновлением bbport** удали комплект. Если установленный файл изменён обновлением или вручную, удаление останавливается и ничего не перезаписывает.

Чтобы временно играть без него, выключи **UI 4K** на странице **Mods** лаунчера.

## Что изменилось с 1.0.0

| | 1.0.0 (aoho60372) | 1.1.1 (этот форк) |
|---|---|---|
| bbport | 1.9.7 | 2.1 |
| Чёткий текст | Только 3840×2160 | Любой вывод 16:9 выше 1080p, пока включён UI 4K |
| Кнопки-подсказки | Только клавиатура; Xbox выключались | Те, что выбраны в лаунчере |
| Меню-ролики | Готовые копии поверх PC-меню порта | Собираются при запуске из версий порта |
| Папки модов | `Keyboard Prompts (PCBButtons)`, `UI 4K`, `Inventory Icons 4K` | Только `UI 4K` |
| Другой мод заменяет архив интерфейса | Игра не запускается | Предупреждение; используется архив того мода без коррекции иконок |
| Картинки флаконов крови и ртутных пуль в HUD | Разрешение игры | Увеличены нейросетью в 2× из оригинальной графики |

## Проблемы

| Сообщение / симптом | Что делать |
|---|---|
| Несовместимый или изменённый bbport | Нужен чистый выпуск 2.1. |
| Путь `mods/Inventory Icons 4K` занят | Сначала удали комплект 1.0.0 (или эту папку). |
| `UI 4K: ... is after UI 4K and replaces its interface archive` | Перемести UI 4K в конец порядка модов. |
| `UI 4K: the inventory icon correction could not be made` | Образ игры порта не поддерживается. Выключи UI 4K, чтобы играть. |
| Неполный или повреждённый комплект | Скачай и распакуй полный ZIP релиза заново. |
